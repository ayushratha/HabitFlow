Common Inquiries

Frequently Asked Questions

Everything you need to know about getting started with HabitFlow.

Which habits come pre-loaded when I create an account?

Every new user automatically starts with three foundational daily habits: Daily Reading (Learning), Focused Study (Productivity), and Water Intake (Health), which you can edit, customize, or expand at any time.

How do the streak calculations work?

Streaks are calculated consecutively based on actual completed records stored in your SQLite database. You maintain an active streak if you log habit progress today, or if you completed habits yesterday and continue today.

How do reminders work?

HabitFlow provides both in-app notification indicators (topbar reminder bell with active countdowns) and standard Web Browser Notifications. Technically, browser notifications run while your browser tab is open.

Can I run and deploy HabitFlow on PythonAnywhere?

Yes! HabitFlow is architected with Python 3.12, standard Flask, and persistent SQLite, with zero external binary bottlenecks, making deployment to PythonAnywhere or any standard Linux VPS seamless.
